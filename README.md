# Eventide — серверная версия соцсети

Настоящий код для запуска на хостинге (не демо-артефакт): лента, рилсы, личные чаты, каналы и музыка в тёмной вечерне-зимней эстетике.

## Стек (продакшен — бесплатные тарифы)

- **Vercel** — хостинг приложения: статика из `public/` раздаётся напрямую, всё остальное и `/api/*` уходит в serverless-функцию `api/index.js` (см. `vercel.json`)
- **Neon Postgres** — база данных (подключение строкой `DATABASE_URL`, SSL включён автоматически для хостов Neon)
- **Vercel Blob** — все медиафайлы: аватарки, фото постов, видео рилсов, аудиотреки. В базе лежат только `secure_url` и `public_id` — постоянного диска приложению не нужно
- **Node.js ≥ 18** + **Express 4** (`app.js` экспортирует app; `server.js` — только локальный запуск)
- Пароли — `bcryptjs`, сессии — httpOnly-cookie + таблица `sessions`
- Фронтенд — vanilla JS SPA без сборки: `public/index.html`, `public/app.js`, `public/style.css`
- Музыкальный каталог — публичный API **Deezer** (без ключей), проксируется сервером

## Переменные окружения

| Переменная | Где нужна | Зачем |
|---|---|---|
| `DATABASE_URL` | прод + локально | Строка подключения Postgres, например `postgres://user:pass@ep-xxx.neon.tech/eventide?sslmode=require` |
| `BLOB_READ_WRITE_TOKEN` | прод + локально | Креды Vercel Blob вида `cloudinary://api_key:api_secret@cloud_name` (берётся в консоли Vercel Blob) |
| `SESSION_SECRET` | прод | Служебный секрет приложения. **На проде обязательно задайте свой** (длинная случайная строка) |
| `PORT` | только локально | Порт `server.js`, по умолчанию `3000` |
| `MEDIA_STUB` | только тесты | `1` — загрузки в Vercel Blob заменяются стабом (файлы никуда не уходят). В проде **не включать** |

## Локальный запуск

Нужен любой доступный Postgres (хоть локальный, хоть Neon):

```bash
npm install
DATABASE_URL='postgres://user:pass@host:5432/eventide' \
BLOB_READ_WRITE_TOKEN='cloudinary://key:secret@cloud' \
SESSION_SECRET='длинная-случайная-строка' \
npm start
# открыто: http://localhost:3000
```

Схема базы создаётся сама при первом запуске (`CREATE TABLE IF NOT EXISTS` в `db.js`).

## Деплой на Render + Neon (по шагам)

Почему так: Vercel не принял российский номер телефона при регистрации, а Cloudinary недоступен в регионе. Render регистрирует через GitHub без телефона, а все данные и медиа живут в Neon — постоянный диск серверу не нужен.

1. **Neon** (база и медиа): зарегистрируйтесь на neon.tech → New Project → откройте **Connection Details** и скопируйте строку подключения — это ваш `DATABASE_URL`. Медиафайлы приложение хранит в таблице `media` той же базы и раздаёт через `/media/:id`.
2. **Render** (приложение): зарегистрируйтесь на render.com через GitHub → **New → Web Service** → подключите этот репозиторий. Build Command: `npm install`, Start Command: `npm start`, план — Free.
3. В настройках сервиса (**Environment**) добавьте переменные: `DATABASE_URL` (строка из Neon) и `SESSION_SECRET` (придумайте длинную случайную строку).
4. Нажмите **Create Web Service**. После деплоя откройте выданный адрес `*.onrender.com` — приложение работает.
5. **Сразу зарегистрируйте первый аккаунт сами** — самый первый зарегистрированный становится владельцем (см. ниже).

⚠️ Бесплатный Render засыпает после ~15 минут без посетителей: первый заход после сна открывается до минуты, дальше всё быстро. Данные при этом не теряются — они в Neon.

## Важные правила продукта

- **Первый зарегистрированный аккаунт = владелец** (`isOwner`): плашка «ВЛАДЕЦ», доступ в админ-панель (список пользователей, выдача/снятие синей галочки верификации). Поэтому на чистом запуске владелец должен регистрироваться **первым**.
- `@username` уникален, один на человека, изменить нельзя; занятый отклоняется с ошибкой «Этот юзернейм уже занят» (регистр не важен).
- Каталожные песни Deezer играют **официальный фрагмент 30 секунд** (ограничение лицензии, в интерфейсе подписано честно). Полностью внутри Eventide играют только **треки, загруженные самими пользователями**.
- «Моя волна» собирается из лайков пользователя: треки лайкнутых артистов + похожие артисты (Deezer related/top); без лайков — из чартов.

## Структура

```
app.js             — весь бэкенд: Express-приложение (API, статика, прокси Deezer), module.exports = app
server.js          — локальный запуск: require app + listen PORT
api/index.js       — точка входа Vercel serverless: module.exports = require('../app')
vercel.json        — rewrites: /api/* и SPA-маршруты → /api/index.js, статика public/ — напрямую
db.js              — пул pg (DATABASE_URL), создание схемы при старте
media.js           — загрузка медиа в Vercel Blob (официальный SDK), типы image/video
public/index.html  — оболочка SPA
public/app.js      — вся клиентская логика (лента, рилсы, чаты, каналы, музыка, профиль)
public/style.css   — темы (CSS-переменные: фиолетовая/красно-чёрная/морозная/таёжная), шрифты, анимации
```

Результаты проверки — в [TESTING.md](TESTING.md).

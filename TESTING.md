# Проверка Eventide (smoke-тесты)

Дата: 2026-11-25. Сервер запускался локально (`PORT=3100 node server.js`), тесты — curl-запросами к API. После тестов база очищена: проект едет на хостинг с пустой `data/`, первый зарегистрировавшийся станет владельцем.

## Результаты — все пункты пройдены ✅

| # | Проверка | Результат |
|---|---|---|
| 1 | Регистрация первого пользователя | `isOwner: true` — владелец назначен автоматически |
| 2 | Регистрация второго пользователя | `isOwner: false` |
| 3 | Дубликат username (в т.ч. другим регистром `MISHA`) | Отклонён: HTTP 409 «Этот юзернейм уже занят» |
| 4 | Создание поста | Пост создан, виден в ленте второго пользователя |
| 5 | Лайк и комментарий к посту | Работают |
| 6 | Сообщение между пользователями | Доставлено; после открытия диалога получателем `read: true` (галочка прочтения) |
| 7 | Создание канала и поста канала | Канал `@vecher` создан, пост опубликован; подписка второго пользователя работает, пост виден в его `channel-feed` |
| 8 | Глобальный поиск | «вечер» нашёл канал «Вечерний канал», «друг» нашёл пользователя (кириллица без учёта регистра — для этого поиск фильтрует в JS, т.к. SQLite LIKE регистр кириллицы не учитывает) |
| 9 | Админка | Владелец выдал галочку верификации второму пользователю (`isVerified: true`); не-владельцу доступ закрыт — HTTP 403 |
| 10 | Поиск Deezer | `/api/music/search` отвечает реальными треками с превью; чарт и «Моя волна» тоже отвечают |
| 11 | Загрузка своего трека | WAV «Test Artist - Test Song.wav» загружен: исполнитель и название распознаны из имени файла, файл раздаётся по `/uploads/...` (HTTP 200), играет целиком |
| 12 | Загрузка рилса (видео) | Видео принято и отдаётся в списке рилсов |
| 13 | Загрузка аватарки | PNG принят, `avatar` появился в профиле |

## Примечание среды

В песочнице сборки `better-sqlite3` не собрался из исходников (node-gyp упёрся в права на распаковку заголовков Node), поэтому локально был поставлен официальный prebuild-бинарник v12.4.1 с GitHub Releases — функционально это тот же пакет. На обычном хостинге `npm install` ставит его штатно.
